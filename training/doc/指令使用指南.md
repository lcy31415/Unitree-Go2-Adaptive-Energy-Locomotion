# 指令使用指南

训练子项目的常用命令速查。所有命令均在仓库根目录的 `training/` 下执行：

```bash
conda activate isaaclab
cd /home/lcy/workspace/papers/Unitree-Go2-Adaptive-Energy-Locomotion/training
```

历史训练日志已随仓库保存在 `training/logs/rsl_rl/` 下，以下命令均使用相对路径引用。

---

### 1. 采用示例模型指定速度演示

```bash
./unitree_rl_lab.sh -p \
  --task Unitree-Go2-Adaptive-Energy-Flat \
  --num_envs 1 \
  --checkpoint /home/lcy/workspace/papers/Unitree-Go2-Adaptive-Energy-Locomotion/training/logs/rsl_rl/unitree_go2_adaptive_energy_flat_lpacrl/2026-08-23_13-49-32/model_7500.pt \
  --command_vx 1.5 \
  --command_vy 0.0 \
  --command_yaw 2.0 \
  --real-time \
  --viz kit \
  --max_visible_envs 1 \
  --follow_robot
```

### 2. 复杂地形指定速度演示

```bash
python scripts/rsl_rl/demo_terrain_policy.py \
  --checkpoint /home/lcy/workspace/papers/Unitree-Go2-Adaptive-Energy-Locomotion/training/logs/rsl_rl/unitree_go2_adaptive_energy_terrain_lpacrl/2026-08-24_22-27-39_terrain_lpacrl_antistand/model_12500.pt \
  --terrain_type random_rough --terrain_level 0 --vx 1.0 --yaw 0.0 \
  --duration_s 120 --viz kit
```

可选地形：`flat / stairs_up / stairs_down / slope_up / slope_down / random_rough`。

### 3. 训练模型

```bash
./unitree_rl_lab.sh -t \
  --task Unitree-Go2-Adaptive-Energy-Flat \
  --num_envs 4096 \
  --max_iterations 5000
```

### 4. 断点继续训练

```bash
./unitree_rl_lab.sh -t \
  --task Unitree-Go2-Adaptive-Energy-Flat \
  --num_envs 4096 \
  --resume \
  --load_run 2026-08-22_01-20-13 \
  --checkpoint model_14999.pt \
  --max_iterations 5001 \
  --run_name resume
```

### 5. 速度追踪测试

```bash
python scripts/rsl_rl/evaluate_speed_tracking.py \
  --task Unitree-Go2-Adaptive-Energy-Flat \
  --checkpoint logs/rsl_rl/unitree_go2_adaptive_energy_flat_lpacrl/2026-08-23_13-49-32/model_7500.pt \
  --speed_min 0.0 \
  --speed_max 5.0 \
  --speed_step 0.20 \
  --envs_per_speed 16 \
  --warmup_s 5 \
  --eval_s 15 \
  --viz none
```

结果默认输出到 checkpoint 旁边的目录（CSV / JSON，可用 `--no_plots` 只导出数据）。
