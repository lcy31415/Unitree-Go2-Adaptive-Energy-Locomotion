# 平地训练任务介绍

本项目的主要训练任务为：

```text
Unitree-Go2-Adaptive-Energy-Flat
```

该任务在一块无限大的水平地面上训练 Unitree Go2 的速度跟踪策略，复现并扩展了 ICRA 2025 论文 *Adaptive Energy Regularization for Autonomous Gait Transition and Energy-Efficient Quadruped Locomotion* 的方法。任务的核心特点是**不提供任何步态先验**：没有 gait clock、没有步态相位、没有接触调度、没有足端轨迹目标，步态完全由"速度跟踪 + 自适应能量正则"在训练过程中自然涌现。

本文详细说明该任务的两个核心设计：

1. 奖励函数设置（第 2 节）；
2. 速度课程设置（第 3 节）。

---

## 1. 任务概览

### 1.1 场景与仿真参数

| 项目 | 设置 |
|---|---|
| 地形 | 无限水平地面（`terrain_type="plane"`） |
| 并行环境数 | 4096 |
| 物理仿真步长 | 0.005 s |
| Decimation | 4（每个控制步 4 次物理仿真） |
| 策略控制频率 | 50 Hz（`step_dt = 0.02 s`） |
| 单条 episode 时长 | 20 s |
| 指令重采样周期 | 10 s（每条 episode 恰好包含 2 个指令分段） |

### 1.2 动作空间

策略输出 12 维动作，映射为 12 个关节的位置目标：

$$q_{\mathrm{des}} = q_{\mathrm{default}} + 0.25 \times a$$

关节由 PD 控制器执行，Sim-to-Sim 验证过的参数为 $K_p = 25.0$、$K_d = 0.5$。

### 1.3 观测空间

策略（Actor）单帧观测 45 维，并叠加 30 帧历史，输入总维度为 45 × 30 = 1350：

| 观测项 | 维度 | 缩放 | 噪声（均匀） |
|---|---|---|---|
| `base_ang_vel` | 3 | 0.2 | ±0.2 |
| `projected_gravity` | 3 | — | ±0.05 |
| `velocity_commands` | 3 | — | — |
| `joint_pos_rel` | 12 | — | ±0.01 |
| `joint_vel_rel` | 12 | 0.05 | ±1.5 |
| `last_action` | 12 | — | — |

Critic 额外获得 `base_lin_vel` 与 `joint_effort` 等特权信息，且观测不带噪声。

### 1.4 步态无关的设计要点

为了让步态"涌现"而不是被"指定"，任务刻意移除了所有常见的步态塑形信号：

- 无 gait clock / 步态相位观测；
- 无期望接触调度、无足端轨迹目标；
- 无高度扫描（Height Scanner）观测；
- 接触传感器的 `track_air_time` 被关闭，奖励中也没有 `feet_air_time` 之类的空中时间奖励——它们本质上都是步态先验。

接触传感器只用于碰撞安全（大腿/小腿碰撞检测）和足端打滑正则。

### 1.5 终止条件

| 条件 | 阈值 |
|---|---|
| 机身底部接触地面 | 接触力 > 1 N |
| 姿态过大（翻倒） | 与重力方向夹角 > 0.8 rad |
| 超时 | 20 s |

### 1.6 域随机化

| 事件 | 设置 |
|---|---|
| 摩擦系数（startup） | 静/动摩擦均 ∈ [0.3, 1.2]，64 桶 |
| 机身质量（startup） | 基础上增加 [−1.0, +3.0] kg |
| 随机推扰（interval） | 每 5–10 s 施加 x/y 方向 ±0.5 m/s 的速度扰动 |
| 重置位姿 | 位置 ±0.5 m、偏航 ±3.14 rad 内均匀随机 |

## 2. 奖励函数设置

### 2.1 总体结构

每个控制步（$\Delta t = 0.02$ s）的奖励为：

$$r_t = \Big( w_{\mathrm{lin}} R_{\mathrm{lin}} + w_{\mathrm{ang}} R_{\mathrm{ang}} + w_{\mathrm{energy}} R_{\mathrm{energy}} \Big) \cdot \exp\!\Big( \frac{R_{\mathrm{aux}} \, \Delta t}{\sigma_{\mathrm{neg}}} \Big) \tag{1}$$

其中：

- $R_{\mathrm{lin}}$、$R_{\mathrm{ang}}$：平面线速度与偏航角速度的跟踪奖励（任务正奖励）；
- $R_{\mathrm{energy}}$：能量效率奖励（任务正奖励）；
- $w_{\mathrm{lin}}, w_{\mathrm{ang}}, w_{\mathrm{energy}}$：随指令速度自适应变化的权重，三者之和恒为 1；
- $R_{\mathrm{aux}} \le 0$：全部正则项（惩罚项）之和，$\sigma_{\mathrm{neg}} = 0.02$。

与传统"正项减负项直接相加"的奖励不同，这里的惩罚以**乘性衰减**的方式作用：由于指数项 $\exp(R_{\mathrm{aux}} \Delta t / \sigma_{\mathrm{neg}}) \in (0, 1]$，惩罚不会把奖励压成负数，但会按比例削弱该步的正奖励。又因为三个正奖励各自 ∈ (0, 1] 且权重和为 1，所以总有 $r_t \in (0, 1]$。

> **实现说明**：Isaac Lab 中该奖励注册为 4 个权重均为 1.0 的 reward term——`Rlin`、`Rang`、`Renergy` 分别返回三个加权正项，`adaptive_energy_residual` 返回"式 (1) 的完整值减去前三个加权项"的残差。四项之和严格等于式 (1)，拆开注册只是为了训练日志和课程评估能独立读取各分量。Isaac Lab 在累计 episode 回报时还会为每步奖励乘以 $\Delta t$。

### 2.2 速度跟踪奖励

对机体坐标系下的实际速度与指令速度之差使用指数核（对应原论文式 (3)）：

$$R_{\mathrm{lin}} = \exp\!\Big( -\frac{(v_x - v_x^{\mathrm{cmd}})^2 + (v_y - v_y^{\mathrm{cmd}})^2}{\sigma} \Big), \qquad \sigma = 0.25 \tag{2}$$

$$R_{\mathrm{ang}} = \exp\!\Big( -\frac{(\omega_z - \omega_z^{\mathrm{cmd}})^2}{\sigma_{\mathrm{yaw}}} \Big), \qquad \sigma_{\mathrm{yaw}} = 0.25 \tag{3}$$

跟踪误差越小奖励越接近 1；$\sigma$ 控制容忍度（这里 $\sqrt{\sigma} = 0.5$）。

### 2.3 能量效率奖励

先定义关节瞬时机械功率：

$$P = \sum_{j=1}^{12} |\dot{q}_j| \, |\tau_j| \tag{4}$$

其中 $\dot{q}_j$ 为关节速度、$\tau_j$ 为关节力矩。能量奖励（对应原论文式 (4)，"单位运动量平均能量"）为：

$$R_{\mathrm{energy}} = \exp\!\Big( -\frac{P}{ \sigma_{\mathrm{lin}} \max(|v_x|, c_{\mathrm{lin}}) + \sigma_{\mathrm{ang}} \max(|\omega_z|, c_{\mathrm{ang}}) } \Big) \tag{5}$$

参数：$\sigma_{\mathrm{lin}} = 1000$，$\sigma_{\mathrm{ang}} = 500$，$c_{\mathrm{lin}} = c_{\mathrm{ang}} = 0.2$。

分母用前进速度和偏航角速度对功率做归一化，得到近似"每米 / 每弧度消耗多少能量"的度量；对速度取 `max(·, c)` 是数值上的下限保护，避免低速/静止时除以接近零的数。

### 2.4 自适应权重（Adaptive Energy Regularization 的核心）

设指令的平面速度模长：

$$s = \big\| (v_x^{\mathrm{cmd}},\, v_y^{\mathrm{cmd}}) \big\|_2 \tag{6}$$

从能量权重中"释放"的量为：

$$\Delta w = \mathrm{clip}\big( 0.3 \, (s - 1.7),\ 0,\ 0.4 \big) \tag{7}$$

则三个权重为：

$$w_{\mathrm{lin}} = 0.4 + \Delta w, \qquad w_{\mathrm{ang}} = 0.2, \qquad w_{\mathrm{energy}} = 0.4 - \Delta w \tag{8}$$

三者之和恒为 1，且均非负。权重随指令速度的变化：

| 指令速度 $s$ | $w_{\mathrm{lin}}$ | $w_{\mathrm{ang}}$ | $w_{\mathrm{energy}}$ | 倾向 |
|---|---|---|---|---|
| $s \le 1.7$ m/s | 0.4 | 0.2 | 0.4 | 跟踪与能量并重 |
| $1.7 < s < 3.03$ m/s | 线性增大 | 0.2 | 线性减小 | 过渡区 |
| $s \ge 3.03$ m/s | 0.8 | 0.2 | 0.0 | 全力跟踪 |

这就是步态涌现的关键机制：**低速时能量权重较大，策略倾向于选择单位距离能耗最低的步态（如 walk）；高速时能量权重让位于跟踪权重，策略被允许切换到能耗高但速度快的步态（如 trot / gallop）**。步态切换不是被指令指定的，而是奖励结构随速度连续变化后的优化结果，即论文标题中的 Autonomous Gait Transition。

### 2.5 正则项 $R_{\mathrm{aux}}$

$R_{\mathrm{aux}}$ 是所有惩罚项的加权和（符号为负）：

$$R_{\mathrm{aux}} = -\Big( 0.02\, v_z^2 + 0.001\, \|\omega_{xy}\|^2 + 0.04\, S_{\mathrm{slip}} + 5.0\, N_{\mathrm{coll}} + 10.0\, \Phi_{\mathrm{lim}} + 10^{-4} \|\tau\|^2 + 10^{-4} \|\dot{q}\|^2 + 2.5 \times 10^{-7}\, \|\ddot{q}\|^2 + 0.1\, S_1 + 0.1\, S_2 + 0.01\, \|\Delta a\|^2 + 5.0\, \|\mathrm{g}_{xy}\|^2 \Big) \tag{9}$$

各项含义：

| 项 | 公式 | 系数 | 说明 |
|---|---|---|---|
| 垂直速度 | $v_z^2$ | 0.02 | 抑制机身上下颠簸 |
| 横滚/俯仰角速度 | $\omega_x^2 + \omega_y^2$ | 0.001 | 抑制机身晃动 |
| 足端打滑 | $S_{\mathrm{slip}} = \sum_{i \in \mathrm{feet}} c_i \, \|v_{i,xy}\|^2$ | 0.04 | $c_i=1$ 当足端本步或上一步接触（垂直接触力 > 1 N），惩罚触地足的水平滑动 |
| 腿部碰撞 | $N_{\mathrm{coll}}$ | 5.0 | 大腿/小腿接触力范数 > 0.1 N 的身体数量 |
| 关节软限位 | $\Phi_{\mathrm{lim}} = \sum_j \big[ \max(0, q_j^{\min} - q_j) + \max(0, q_j - q_j^{\max}) \big]$ | 10.0 | $q^{\min}, q^{\max}$ 为软关节限位 |
| 力矩 | $\|\tau\|^2 = \sum_j \tau_j^2$ | 1e-4 | 抑制过大力矩 |
| 关节速度 | $\|\dot{q}\|^2 = \sum_j \dot{q}_j^2$ | 1e-4 | 抑制过快关节运动 |
| 关节加速度 | $\|\ddot{q}\|^2 = \sum_j \big( (\dot{q}_{t,j} - \dot{q}_{t-1,j}) / \Delta t \big)^2$ | 2.5e-7 | 平滑关节运动 |
| 平滑一阶 | $S_1 = \sum_j (p_{t,j} - p_{t-1,j})^2$ | 0.1 | $p$ 为处理后的关节位置目标，抑制目标突变 |
| 平滑二阶 | $S_2 = \sum_j (p_{t,j} - 2 p_{t-1,j} + p_{t-2,j})^2$ | 0.1 | 抑制目标的加速度 |
| 动作变化率 | $\|\Delta a\|^2 = \sum_j (a_{t,j} - a_{t-1,j})^2$ | 0.01 | 平滑策略输出 |
| 姿态 | $\|\mathrm{g}_{xy}\|^2 = g_x^2 + g_y^2$ | 5.0 | 投影重力 xy 分量，保持机身水平 |

在当前参数下 $\Delta t / \sigma_{\mathrm{neg}} = 0.02 / 0.02 = 1$，因此式 (1) 中的衰减因子即为 $e^{R_{\mathrm{aux}}}$：正则项越差，该步奖励按指数衰减越多。

> 与对照任务 `Unitree-Go2-Velocity`（`velocity_env_cfg.py`）的区别：对照任务采用传统的**加性**奖励——`exp` 核跟踪项（权重 1.5 / 0.75）加上一系列负权重惩罚项（含 `feet_air_time`、`air_time_variance` 等步态塑形项）。主任务去掉了全部步态塑形项，并改为上述乘性衰减结构。

## 3. 速度课程设置

主任务的速度课程由 `RewardThresholdVelocityCommand` 实现：把三维速度指令离散成网格，用**基于物理误差的阈值判据**逐格解锁，并按 `v_x → 偏航 → 侧移` 的顺序分阶段开放指令空间。

> 为什么由指令生成器自己驱动课程，而不是 Isaac Lab 的 CurriculumManager？因为课程更新必须与 10 秒指令分段精确同步，而 CurriculumManager 以环境 reset 为触发点，无法复现参考实现的分段计时。因此 `AdaptiveEnergyEnvCfg` 中 `curriculum = None`，课程完全由指令生成器在每个分段结束时更新。

### 3.1 指令网格

三维指令 $(v_x, v_y, \omega_z)$ 的限制范围与离散网格：

| 轴 | 限制范围 | 网格数 | 网格宽度 |
|---|---|---|---|
| $v_x$ | [−5, 5] m/s | 21 | ≈ 0.476 m/s |
| $v_y$ | [−0.6, 0.6] m/s | 13 | ≈ 0.092 m/s |
| $\omega_z$ | [−5, 5] rad/s | 21 | ≈ 0.476 rad/s |

每个网格单元（cell）维护一个权重 $w \in [0, 1]$，表示该指令区域的"激活程度"。三个轴都使用奇数网格，保证每个轴上存在真正的零中心单元。

初始时只有初始范围内的单元被激活（$w = 1$）：

$$v_x \in [-1, 1] \ \mathrm{m/s}, \qquad v_y = 0, \qquad \omega_z = 0$$

即初始仅 5 个低速单元（$|v_x| \le 0.96$ m/s 的单元中心）可用，其余单元权重为 0。

### 3.2 成功判据（每 10 秒分段评估）

指令每 10 s 重采样一次。在一个分段内，逐控制步累积机体坐标系下三轴速度的绝对误差，分段结束时求平均：

$$\bar{\varepsilon}_x = \frac{1}{N} \sum_t |v_x - v_x^{\mathrm{cmd}}|, \qquad \bar{\varepsilon}_y,\ \bar{\varepsilon}_\omega \ \text{同理} \tag{10}$$

该分段判定为"成功"需同时满足：

$$\bar{\varepsilon}_x \le \max(0.1,\ 0.033\, |v_x^{\mathrm{cmd}}|) \tag{11}$$

$$\bar{\varepsilon}_y \le \max(0.15,\ 0.1\, |v_y^{\mathrm{cmd}}|) \tag{12}$$

$$\bar{\varepsilon}_\omega \le \max(0.2,\ 0.1\, |\omega_z^{\mathrm{cmd}}|) \tag{13}$$

$$N \ge 0.95 \times N_{\mathrm{expected}} \tag{14}$$

其中 $N_{\mathrm{expected}} = 10\ \mathrm{s} / 0.02\ \mathrm{s} = 500$ 步，即分段完整度不低于 95%（机器人中途摔倒重置会打断分段）。容差取"绝对下限"与"相对容差"的较大者：低速时用绝对容差，高速时允许按指令幅值 3.3%～10% 的相对误差。

判据基于**物理速度误差**而非奖励值，因此不受奖励量纲与权重调整的影响。环境重置后的第一次指令计算不计入误差统计。

### 3.3 权重更新与邻域解锁

每个分段结束时，对成功分段所在的网格单元 $b$ 执行两步更新：

1. 成功单元自身：$w_b \mathrel{+}= 0.2$；
2. 笛卡尔邻域：与成功单元逐轴距离不超过 `local_range = (0.55, 0.10, 0.55)` 的所有当前阶段允许的单元（**含成功单元自身**），每个单元 $w \mathrel{+}= 0.2 \times n_b$，其中 $n_b$ 为落在该单元上的成功分段数。

最后裁剪到 $[0, 1]$，被锁定轴上的单元权重强制为 0。由于邻域包含单元自身，一个成功的单元一次至少获得 $0.2 + 0.2 = 0.4$ 的权重，即一次成功就足以解锁该单元及其邻域。课程因此从初始低速区出发，随训练连续地向高速/侧移/转向区域扩张。

### 3.4 分阶段解锁：v_x → 偏航 → 侧移

指令空间不是一次性全部开放，而是按三个阶段逐步解锁：

| 阶段 | 解锁的轴 | $v_y$ | $\omega_z$ | 进入条件 |
|---|---|---|---|---|
| Stage 0 | $v_x$ | ≡ 0 | ≡ 0 | 初始状态 |
| Stage 1 | $v_x,\ \omega_z$ | ≡ 0 | 自由 | Stage 0 下累计 20 个成功分段且指令 $v_x \ge 2.5$ m/s |
| Stage 2 | $v_x,\ v_y,\ \omega_z$ | 自由 | 自由 | Stage 1 下累计 20 个成功分段且指令 $|\omega_z| \ge 2.5$ rad/s |

设计动机：先集中训练纵向速度——这是步态涌现的主轴；前进速度达标后再开放转向；最后才开放侧移（四足机器人侧移最难，也最少用）。被锁定轴上的单元权重恒为 0，采样出的指令值也精确为 0。

### 3.5 混合采样策略

每次指令重采样时，每个环境按如下概率从三类来源独立抽取一个网格单元：

| 来源 | 概率 | 说明 |
|---|---|---|
| 前沿 frontier | 0.4 | 当前阶段正在扩张的轴上、激活单元中最外侧 2 层 bin 组成的带（Stage 0 取 $v_x$ 代数值，即优先**正向**速度前沿；Stage 1/2 分别取 $\|\omega_z\|$、$\|v_y\|$ 绝对值） |
| 全体激活均匀 active | 0.4 | 从当前所有激活单元中均匀采样 |
| 低速重放 replay | 0.2 | 从初始激活的低速单元中均匀采样 |

抽取后在单元内叠加 $\pm$ 半网格宽度的均匀噪声，锁定轴置 0，并裁剪回限制范围。

设计动机：单元权重保留参考实现的增量激活规则，但**采样概率与权重解耦**——若直接按权重采样，大量已训练充分的低速单元会稀释前沿难例的训练；40% 前沿采样保证持续推进课程，40% 均匀采样维持已解锁区域的覆盖，20% 低速重放防止策略遗忘低速步态（walk）。低速步态恰恰是能量正则化最起作用的区域，遗忘它会导致步态切换链条断裂。

### 3.6 指令后处理

平面指令模长 $\|(v_x, v_y)\| \le 0.2$ m/s 时，将其精确置 0，避免机器人在极小指令下做无意义的抖动跟踪。配置中 `rel_standing_envs = 0.0`，站立概率由网格采样自然产生而不是强制指定。

### 3.7 训练监控指标

课程状态通过如下 metrics 写入训练日志（TensorBoard / logger），可用于判断训练进度：

| 指标 | 含义 |
|---|---|
| `curriculum_stage` | 当前阶段（0 / 1 / 2） |
| `curriculum_stage_progress` | 当前阶段的推进度（成功分段数 / 20） |
| `curriculum_active_fraction` | 允许范围内激活单元占比 |
| `curriculum_mean_weight` | 允许范围内单元平均权重 |
| `curriculum_success` | 最近分段是否成功 |
| `curriculum_error_vx / vy / yaw` | 最近分段的三轴平均绝对误差 |
| `sample_frontier / active_uniform / low_speed_replay` | 最近一次采样的来源 |

### 3.8 对照：`Unitree-Go2-Velocity` 任务的课程

对照任务（`velocity_env_cfg.py`）使用简单的"范围扩张"式课程（`lin_vel_cmd_levels`，作用于 `UniformLevelVelocityCommand`）：

- 初始指令范围：$v_x \in [-0.1, 0.1]$、$v_y \in [-0.1, 0.1]$、$\omega_z \in [-1, 1]$；
- 上限范围：$v_x \in [-1, 1]$、$v_y \in [-0.4, 0.4]$、$\omega_z \in [-1, 1]$；
- 每经过一个 episode 时长（20 s），若归一化的线速度跟踪奖励超过阈值（0.8 × 跟踪项权重 1.5），则 $v_x$、$v_y$ 的范围同时向外扩张 ±0.1 m/s，直至上限。

主任务的网格阈值课程与之相比有三点优势：判据基于物理误差而非奖励值、逐格解锁粒度更细、混合采样显式平衡难例与重放。

## 4. 参数速查

### 4.1 奖励参数（`AdaptiveEnergyRewardsCfg`）

| 参数 | 值 | 说明 |
